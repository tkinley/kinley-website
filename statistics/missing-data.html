Analysis populations, missing data, and sensitivity

Who gets analyzed, and how absent outcomes are handled, can change a result. Missing data are a scientific problem about what was not observed, rather than simply an empty-cell problem.

Numerical examples on this page are hypothetical unless a worked case study is explicitly linked.

Learn by changing the example

Explore assumptions about missing outcomes

Start with a 50% response rate among observed patients. Change how many outcomes are missing and the response rate assumed for them.

The full-cohort value is a sensitivity scenario, not an estimate justified by the observed data alone. All missing patients share the selected assumed response rate. No claim about MAR, MNAR, or a particular imputation method is established here.

Keep the analysis population explicit

The intention-to-treat principle evaluates randomized patients according to their assigned group, preserving the planned comparison as far as possible. A full analysis set may implement that principle with defined exceptions. A modified intention-to-treat set needs an exact definition; its label alone does not establish which exclusions were made.

A per-protocol set excludes certain protocol deviations. An as-treated analysis follows treatment received. An evaluable population may exclude missing assessments. Such selections can break the comparability created by randomization, particularly when exclusions relate to prognosis or treatment response.

An exclusion can change the apparent rate

Example: response assessments are missing

Of 100 randomized patients, 40 have a documented response, 40 have a documented nonresponse, and 20 lack an assessment. The observed-assessment rate is 40/80 = 50%. Counting every missing assessment as nonresponse gives 40/100 = 40%.

Neither number reveals the missing patients’ unobserved outcomes. A nonresponse rule may be part of an endpoint or analysis, but is not automatically conservative for a treatment contrast if missingness differs between arms. The estimand and scientific assumptions must explain the choice.

Three missingness assumptions

Missing completely at random (MCAR) means missingness does not depend on observed or unobserved study data. Missing at random (MAR) allows dependence on observed information but, conditional on that information, not on the missing values. Missing not at random (MNAR) allows dependence on the missing values even after conditioning on observed data.

MAR does not mean missingness is harmless or literally random in everyday language. Data alone usually cannot establish MAR versus MNAR, because the relevant values are unobserved. Reasons and timing of missingness are therefore important.

Estimation needs assumptions; sensitivity challenges them

Multiple imputation draws plausible missing values under a model and combines analyses so that imputation uncertainty is included. A mixed model for repeated measures can use observed longitudinal outcomes under its model and missingness assumptions. Neither method guarantees unbiased estimates when those assumptions are wrong.

Last observation carried forward treats a previous value as the later missing value; it can impose unrealistic outcome trajectories and understate uncertainty. Sensitivity analyses vary plausible assumptions while addressing the same estimand. A tipping-point analysis asks how unfavorable the missing outcomes would need to be to change a conclusion.

Treatment changes are not all missing data

Stopping treatment, using rescue therapy, and death can affect which outcome is meaningful even when data are collected. They are intercurrent events handled within the estimand. Missingness refers to the absence of information needed to estimate that target.

Read the randomized count, analyzed count, reasons for exclusion, follow-up completeness by arm, outcome collection after discontinuation, primary assumptions, and sensitivity analyses together.
