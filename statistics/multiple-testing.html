Multiple testing and false discoveries

Testing more endpoints, doses, subgroups, or analysis times creates more opportunities for a chance finding. A persuasive result needs an account of the full set of opportunities to claim success.

Why many tests change the picture

If twenty independent tests all have true null hypotheses and each uses α = 0.05, the probability of at least one rejection is 1 − 0.95²⁰ ≈ 64.2%. This is an illustrative independence calculation. Real endpoints are often correlated, so that exact number does not generally apply, but the multiplicity problem remains.

A testing family groups hypotheses for which a joint error criterion is controlled. Endpoint ordering, dose comparisons, subgroup tests, and interim looks can contribute to the testing strategy.

Control the chance of any false positive in a family

Family-wise error rate (FWER) is the probability of at least one false rejection in the defined family. Bonferroni compares each of m p-values with α/m and controls FWER without requiring independence. With twenty tests and α = 0.05, the threshold is 0.0025 per test.

Holm’s method orders p-values and uses successive thresholds α/m, α/(m−1), and so on, stopping when a comparison fails. It also controls FWER under general dependence and can reject more hypotheses than simple Bonferroni.

A prespecified fixed-sequence hierarchy can pass alpha through an ordered set of hypotheses. Its validity depends on following its rules; a favorable secondary endpoint does not automatically support a confirmatory claim after a failed gate.

FDR controls a different quantity

False discovery rate (FDR) is the expected fraction of false rejections among all rejections, with fraction zero when none are rejected. The Benjamini–Hochberg procedure orders m p-values and finds the largest rank k satisfying p(k) ≤ (k/m)q, then rejects through that rank.

The usual guarantee applies under independence and certain positive-dependence conditions, not every dependency structure. FDR methods are useful in exploratory settings such as biomarker screens. They are not interchangeable with FWER control for confirmatory claims.

Interpret the testing plan before the smallest p-value

Look for the prespecified family, primary endpoint structure, alpha allocation, interim monitoring, and any testing hierarchy. Distinguish adjusted p-values from nominal p-values. If multiple co-primary endpoints must all succeed, that design has a different error structure from claiming success if any one succeeds.

Unreported searches make a favorable result hard to evaluate. An exploratory finding can be valuable as a hypothesis while still needing prospective confirmation.
