Concept 7.1

Identify the independent unit

Sixty records might come from only 12 collection events, with five observations per event.

  1. Find which units were sampled or assigned independently.
  2. Group records that share a collection event, site, or batch where their outcomes may be dependent.
  3. Choose an uncertainty or randomization procedure that reflects the design and the limited number of independent units.

The row count can overstate independent information. Stratification and accounting for dependence solve different problems.

Try it · Does adding a batch indicator guarantee independent residuals?

No. Records from the same event can still be correlated.

Concept 7.2

Separate estimability from testability

Suppose both groups appear in every target stratum and both rates are observed, even if all outcomes are constant.

  1. Compute the within-stratum differences and their weighted average. Those descriptive quantities are defined.
  2. Check whether the test statistic can vary under the fixed-margin null.
  3. Check whether the interval method handles boundaries and uses defensible sampling assumptions.

A defined estimate can have a degenerate permutation test and a nonzero uncertainty interval.

Try it · What makes a standardized difference undefined without extrapolation?

Positive target weight on a stratum where a required group rate is unobserved.

Concept 7.3

Match method to the question

Suppose three analysts report a standardized prevalence difference, a conditional odds ratio, and an exact p-value.

  1. Ask which quantity each method targets. The difference is measured in percentage points, and the odds ratio is a relative odds measure.
  2. Check which strata and sampling assumptions each method uses.
  3. Compare estimates on the same target and effect scale first. Interpret a p-value using the test’s null and statistic.

Results can differ because the methods answer different questions. State those questions before comparing the numbers.

Try it · Can a p-value of 1 prove that the difference is exactly zero?

No. For example, a fixed outcome pattern gives no way for the blocked test statistic to change.

Concept 7.4

Read sensitivity analyses

A sensitivity analysis changes one choice at a time so you can see what drives the result.

  1. Separate changes in estimand, such as different reference weights, from changes in how the same estimand is estimated.
  2. Keep a record of overlap, sample sizes, and the assumptions behind each comparison.
  3. Check whether large changes come from a sparse cell, a different target, or the handling of dependence.

Explain which change caused a result to move and whether the interpretation moves with it.

Try it · If A-based and equal weights give opposite signs, what would you show?

Show stratum-specific effects, both weight vectors, and both summaries.

Concept 7.5

Keep the claim within the design

A selected collection can describe its own observations. A broader claim requires support from the sampling or causal design.

  1. State what population the comparison represents and how the data were acquired.
  2. Distinguish an observed association from a causal interpretation or a mechanism.
  3. Name the assumptions needed to generalize beyond the observed collection.

A precise estimate can still answer a narrow question.

Try it · Would collecting more observations using the same biased selection rule fix generalizability?

More observations may improve precision while leaving the selection bias in place.

Concept 7.6

Write the result in one paragraph

Use the three results in Figure 7 to give a short, bounded interpretation.

  1. Report the observed pooled difference of +12 pp.
  2. State how the estimate changes when both groups get the same reference mix: −4 pp.
  3. Give the interval (−13 to +5 pp), identify the target, and mention the overlap and sampling assumptions relevant to that estimate.

Lead with the comparison, name the adjustment, then communicate how uncertain the estimate is.

Try it · Does the adjusted result show equivalence within ±5 pp?

No. The interval extends below −5 pp. Equivalence requires an explicit margin and a method suited to that question.
