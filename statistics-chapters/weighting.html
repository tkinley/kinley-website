Standardize to a target

Define the estimand, calculate common weights, and see how a single observation can move it.

Concept 3.1

State the estimand

An estimand specifies the exact question before you pick the estimator.

  1. Name the outcome: whether a unit passed inspection.
  2. Choose the measure and direction: the A-minus-B prevalence difference.
  3. Name the target: the observed distribution of batches among units in A.

The estimand is a weighted average of within-batch differences using A’s batch shares.

Try it · What changes if you switch to equal batch weights?

The target becomes an average across equally weighted batches.

Concept 3.2

Find each batch’s difference

This example has different effects in X and Y.

  1. In X, subtract 5/6 − 3/18 = 2/3 ≈ +66.7 pp.
  2. In Y, subtract 6/18 − 15/22 = −23/66 ≈ −34.8 pp.
  3. Keep fractions until the final rounding step.

The directions differ. A single summary will depend on which batch gets more weight.

Try it · What would a weight of 100% on Y report?

The within-Y difference, about −34.8 pp.

Concept 3.3

Choose common weights

Standardization applies the same target mix to both source groups.

  1. Count A’s observations by batch: 6 in X and 18 in Y.
  2. Divide by the A total of 24: wX = 6/24 = 0.25 and wY = 18/24 = 0.75.
  3. Apply those weights to A and to B. Check that all weights are nonnegative and sum to 1.

Each weighted rate represents the same mix of batches.

Try it · What weights match the full cohort?

X has 6 + 18 = 24 out of 64, so wX = 0.375 and wY = 0.625.

Concept 3.4

Multiply and add

With common weights, you can standardize each rate first or average the differences directly.

  1. Multiply X’s gap by its weight: 0.25 × (2/3) = 0.16667.
  2. Multiply Y’s gap: 0.75 × (−23/66) ≈ −0.26136.
  3. Add the contributions: 0.16667 − 0.26136 ≈ −0.09470, or −9.5 pp.

A’s standardized rate is about 9.5 percentage points below B’s at A’s mix.

Try it · What is the unadjusted pooled gap?

11/24 − 18/40 ≈ +0.8 percentage points.

Concept 3.5

Compare target choices

The same within-batch differences can support several valid summaries for different targets.

  1. Use 25% on X for A’s mix: about −9.5 pp.
  2. Use 37.5% on X for the full cohort mix: about +3.2 pp.
  3. Use 50% on X for equal weights: about +15.9 pp. Check each value using Figure 3.

Specify the target before seeing the result. A sign change across targets can reflect effect heterogeneity.

Try it · What fixed values are you averaging?

Approximately +66.7 pp in X and −34.8 pp in Y.

Concept 3.6

Compute one-observation leverage

Leverage here is how much the standardized difference changes if one binary outcome flips, holding denominators and weights fixed.

  1. Changing one outcome in a cell of size n changes its rate by 1/n.
  2. Multiply by the batch weight: the change has magnitude w/n.
  3. In X, an A flip has magnitude 0.25/6 ≈ 4.17 pp. A B flip has magnitude 0.25/18 ≈ 1.39 pp and enters with the opposite sign for the same direction of flip.

Small denominators can make individual records matter. Check whether a result rests on a few observations.

Try it · How much does the difference move if a B outcome in X changes from No to Yes?

It decreases by about 1.39 pp because the B rate is subtracted.
