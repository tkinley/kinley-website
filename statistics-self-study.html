    Measuring association

    Which number answers the question: how many more, how many times as common, or how many times the odds?

    Prevalence
    Carriers ÷ total genomes. The prevalence difference is A’s prevalence minus B’s, reported in percentage points.
    Prevalence ratio
    A’s prevalence ÷ B’s. Use B as the reference and give both rates for context.
    Odds ratio
    Compute carriers ÷ noncarriers in each group, then divide A’s odds by B’s. Odds can exceed 1.

    Worked example

    Group A has 18/24 carriers (75%). Group B has 20/40 (50%).

    Difference
    75% − 50%+25 pp
    Prevalence ratio
    0.75 ÷ 0.501.5
    Odds ratio
    (18/6) ÷ (20/20)3
    Recall checkWhat if B has zero carriers?

    If A has any carriers and B has zero, the raw odds ratio is infinite. With zero carriers in both groups it is undefined (0 ÷ 0). Show the counts and choose an uncertainty method that handles sparse data.

    Population structure

    Could the pooled result come from which lineages are in each group?

    Pooled vs. stratified
    Pooling combines all observations. Stratification compares A and B separately inside each lineage.
    Population structure
    Lineages can differ in gene prevalence and in how often they appear in each source. This can create or obscure a pooled association.
    Overlap
    A direct within-lineage comparison requires both sources in that lineage. An absent source has unknown prevalence there.

    Worked example

    Every genome in X carries the gene. No genome in Y does.

    Carriers / total in each group
    ComparisonABA − B
    Within X8/82/20 pp
    Within Y0/20/80 pp
    Pooled8/102/10+60 pp

    Group A has more genomes from X. That difference in mix explains the entire pooled gap.

    Recall checkDoes a change in the adjusted odds ratio establish confounding?

    A marginal odds ratio and a conditional odds ratio can differ even when the groups have the same lineage mix. This is called noncollapsibility. Assess confounding using the study design and the role of each covariate. Greenland, Robins & Pearl

    Standardization

    What would the difference be if both sources had the same lineage mix?

    Estimand
    The exact target quantity. Specify the outcome, compared groups, effect measure, and target population.
    Standardized difference
    Multiply each lineage’s A-minus-B difference by its reference weight and add. The same weights apply to both sources and sum to one.
    Effect heterogeneity
    The association can vary in size or direction by lineage. Different reference weights can then produce different summaries.

    Worked example

    In X, A has 5/6 carriers and B has 3/18 (+66.7 pp). In Y, A has 6/18 and B has 15/22 (−34.8 pp).

    A’s mix
    25% × X gap + 75% × Y gap−9.5 pp
    Equal weights
    50% × X gap + 50% × Y gap+15.9 pp

    Use the exact fractions and round at the end. Each result describes a different target mix.

    Recall checkWhat if one lineage has no source B data?

    For direct standardization, restrict to lineages with both sources and rescale their weights, then name the narrower target. A model that retains the original target needs extra assumptions to extrapolate.

    Statistical uncertainty

    Read the estimate, interval, and p-value together. Each answers a different question.

    Effect estimate
    The measured magnitude and direction, such as +8 percentage points for A compared with B.
    95% confidence interval
    Over repeated samples, a valid procedure would cover the fixed target about 95% of the time under its assumptions. A wider interval reflects less precision.
    P-value
    Under the null and test assumptions, the probability of a test statistic at least as extreme as the one observed.

    Worked example

    Estimate
    +8 pp
    95% interval
    −3 to +19 pp
    P-value
    0.15

    The observed difference favors A. Under the model, the interval includes zero and spans a small decrease to a potentially meaningful increase.

    Recall checkDoes an interval that includes zero demonstrate equivalence?

    Equivalence needs a prespecified margin and an appropriate test. An interval from −3 to +19 pp extends well past a +5 pp margin. NIST on confidence intervals, ASA on p-values

    Permutation and FDR

    Build a valid null comparison, then account for how many hypotheses you tested.

    Permutation test
    Choose a statistic and tail rule, then recompute the statistic after permitted source-label swaps. Swaps within lineages preserve source totals there.
    Exchangeability
    The null must justify those swaps. Shared sampling events or residual dependence can make individual-genome swaps invalid.
    False discovery rate (FDR)
    The expected fraction of false rejections among all rejections. That fraction is zero when there are no rejections.

    Two worked examples

    Permutation. If 19 of 999 random shuffles are at least as extreme, the plus-one Monte Carlo p-value is (19 + 1) ÷ (999 + 1) = 0.020. Phipson & Smyth

    Benjamini–Hochberg. Sort 0.004, 0.018, 0.041, 0.2. At 5% FDR with four tests, compare to 0.0125, 0.025, 0.0375, 0.05. Rank 2 is the largest passing rank, so reject the first two. Benjamini & Hochberg

    Recall checkWhat should you verify before interpreting adjusted results?

    Define the test family and check that each p-value is valid. Choose an adjustment whose assumptions fit the dependence among tests. Report effect sizes and support counts alongside the adjusted evidence.

    Study design and interpretation

    Your conclusion can only be as broad as the sampling, measurements, and comparison support.

    Sampling unit
    Genomes can share a sampling event, a site, or recent ancestry. Identify what was sampled independently before choosing standard errors or resampling units.
    Selection and generalization
    Specify who or what the selected collection represents. Increasing the sample size can improve precision while preserving selection bias.
    Association and mechanism
    Use the data to describe how gene prevalence varies by source. A claim about biological mechanism needs additional evidence.

    Frame an interview answer

    1. Define the target. Name the outcome, comparison, scale, and population.
    2. Check the data. Inspect missing calls, overlap, strata sizes, and sampling units.
    3. Estimate and quantify uncertainty. Choose methods suited to the data and account for multiple tests where relevant.
    4. State the scope. Give the effect, uncertainty, and limits on generalization.
    Recall checkAre ten genetic lineages ten independent sampling events?

    Lineage records ancestry. A sampling event records how observations were collected. Check both, then choose units that reflect how the data were generated.
