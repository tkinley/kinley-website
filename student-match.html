How privacy and matching work

This page downloads its own static files, data, fonts, and parsers. The matcher has no analytics. Document text is processed transiently in a worker, then discarded; only allowlisted suggestions return to this page. A file may contain sensitive details: remove those before selecting it. Profile answers remain in this tab’s memory and are cleared on reload or reset. Following a resource link takes you to that provider’s website.

Matching uses explicit rules and keywords, with no LLM. Relevance describes fit with your interests, never a chance of winning an award. Unverified requirements stay unknown.
